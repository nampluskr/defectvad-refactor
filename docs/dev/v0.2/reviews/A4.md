## 1. 검증 개요

`docs/dev/v0.2/PLAN.md`의 Phase 6 (Tier 2 모델 포팅)에 정의된 3개 모델에 대해 anomalib v2.3.0 원본과의 SSOT 무결성, Lightning 의존성 완전 제거, 로컬 자산 오프라인 실행, 공통 engine 비오염성, 다단계/다중 옵티마이저 동등성을 검증하였다.

| 모델 | SSOT 원본 경로 | 포팅 파일 수 | 주요 아키텍처 / 학습 패러다임 |
|---|---|---|---|
| GANomaly | `image/ganomaly/` | 2 | Generator-Discriminator 적대적 생성 + 잠재 공간 오차 기반 점수 산출 (Image-level Only) |
| DRAEM | `image/draem/` | 2 (+ sspcab, perlin, multi_random_choice) | 재구성 네트워크 + 판별 서브네트워크 + DTD/Perlin 인공 결함 합성 지도학습 |
| DSR | `image/dsr/` | 3 | VQ-VAE 이산 코드북(Pretrained) 기반 듀얼 서브스페이스 재투영 + 2단계 다중 옵티마이저 학습 |

## 2. 규칙별 검증 결과

### 2.1 CON-001 (SSOT 원본 무수정 원칙) — 통과
- `diff -u`를 통해 원본 anomalib 파일과 포팅 파일 간 비교를 수행하였다.
- 모든 모델 파일(`torch_model.py`, `loss.py`, `anomaly_generator.py`)에서 **import 경로 치환 이외의 코드/로직/하이퍼파라미터 변경은 0줄**임을 실측 확인하였다.

### 2.2 CON-002 (Lightning 완전 배제) — 통과
- `src/tasks/anomaly/models/`, `src/tasks/anomaly/adapters/`, `configs/anomaly/models/` 전체에 대해 `lightning`, `pytorch_lightning`, `LightningModule`, `Trainer` import 및 호출 여부를 전수 검사하였다.
- 잔재 0건 확인.

### 2.3 CON-003 / CON-004 (오프라인 실행 및 로컬 자산 강제) — 통과
- `GANomaly`: 사전학습 가중치 불필요 (from scratch 학습).
- `DRAEM`: DTD 텍스처 데이터셋을 로컬 `/mnt/d/datasets/dtd`에서 직접 로드하며 인터넷 다운로드 경로 없음.
- `DSR`: 이산 VQ-VAE 사전학습 가중치 `vq_model_pretrained_128_4096.pckl`을 로컬 `/mnt/d/backbones`에서 직접 로드하며 인터넷 다운로드 경로 없음.

### 2.4 NFR-005 (Task-Agnostic 공통 Engine) — 통과
- `src/core/engine.py`에 모델명이나 태스크명 분기(`if model == ...`, `if task == ...`)가 전혀 없음을 확인하였다.
- `GANomaly` 및 `DSR`의 다중 옵티마이저(Generator/Discriminator, Stage 2/Stage 3) 스케줄링은 각각의 `TaskAdapter`(`GanomalyAdapter`, `DsrAdapter`) 내부에서 캡슐화되어 Engine에 더미 무손실 그래디언트를 반환하므로 공통 루프의 독립성을 완벽히 보존하였다.
