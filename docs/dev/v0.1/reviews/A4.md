2. `data.batch_size`가 1로 유지되는지 (SPEC §4.5 — EfficientAD train batch size 고정 요건)
3. `data.transform.train/eval`의 `normalize: false`가 유지되는지 (upstream `torch_model.py` 내부 정규화와의 이중 정규화 방지)
4. `model.params.weights_path`, `adapter.params.auxiliary_root`가 `${paths.*}` placeholder를 유지하는지 (CON-003, 경로 이식성)
5. `adapter.params.auxiliary_seed`와 `runtime.seed` 동기화 필요성이 주석으로 남아 있는지
